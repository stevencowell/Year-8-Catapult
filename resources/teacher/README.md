# Integrated teacher-resource package

This directory contains the final editable 25-lesson teaching program, delivery register and their traceability manifests. The two Word documents and all ten classroom presentations are linked from `teacher-resources.html`.

The program remains a provisional local planning scaffold. Exact timetable, practical controls, testing conditions and formal assessment details still require teacher confirmation before issue. Named student submissions, marks, photographs and private Classroom material are excluded.
