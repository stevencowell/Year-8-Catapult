Course-wide activity bank

Applied Learning Activities

Use these tasks for revision, a fast finish, a relief lesson or a second way into a difficult concept. They are connected to the course—not disconnected busy work.

Use the right conditions

These are classroom learning activities. Any practical handling, demonstration or test still follows your teacher's directions and local controls.

Activity 1

System chain sorter

Rebuild the Catapult system from concept cards and explain why a set of parts is not automatically a system.

25 minutes

Open the activity

What you need

  • website fields
  • optional paper and pencil
  1. Sort concept cards into input, process, output or feedback.
  2. Order a neutral component chain from energy input to observable output.
  3. Choose two neighbouring components and explain their interaction.
  4. Predict one downstream effect if a component becomes misaligned.

Evidence: Completed sort and two interaction explanations, saved as formative practice.

Type the response, reasoning or record requested above. It autosaves in this browser.

Ready to save0 characters

Support: Start with what enters, what changes, what can be observed and what information returns to the designer.

Extension: Add a second feedback path and explain the decision it could influence.

Activity 2

Criteria clinic

Distinguish authorised constraints from useful criteria and repair vague evaluation statements.

20 minutes

Open the activity

What you need

  • website fields
  • optional paper and pencil
  1. Sort eight statements into criterion, constraint, evidence or unsupported claim.
  2. Explain why the 2400 mm planned-pine limit is a constraint.
  3. Rewrite ‘works well’ as an observable criterion without inventing a threshold.
  4. Match one evidence type to the rewritten criterion.

Evidence: Sort result, repaired criterion and evidence match, saved as formative practice.

Type the response, reasoning or record requested above. It autosaves in this browser.

Ready to save0 characters

Support: A constraint limits the design; a criterion describes what could be judged; evidence is what was observed or measured.

Extension: Write a criterion–evidence–judgement–improvement loop for the repaired criterion.

25 minutes

What you need

  2. Identify the material property that matters in two scenarios.
  3. Mark each scenario proceed-after-demonstration, stop-and-ask or not-authorised-from-source.
  4. Justify one decision using hazard, control and authority language.

Evidence: Function matches and one justified triage decision, saved as formative practice.

Activity 4

Lever moment reasoning lab

Apply moment = force × perpendicular distance and explain the design trade-off in words.

25 minutes

Open the activity

What you need

  • website fields
  • optional paper, pencil and ruler
  1. Label effort, pivot, load, effort arm and load arm on a generic lever diagram.
  2. Calculate moments for three supplied non-project examples with units.
  3. Identify which example is balanced and justify the decision.
  4. Explain one trade-off created by increasing an arm length.

Evidence: Label set, calculations and trade-off explanation, saved as formative practice.

Type the response, reasoning or record requested above. It autosaves in this browser.

Ready to save0 characters

Support: Multiply force by perpendicular distance from the pivot and compare moments on opposite sides.

Extension: Create a new balanced numerical example that is clearly labelled as theory, not a project dimension.

Activity 8

Quality fault evidence matrix

Separate observations from causes and choose evidence that could distinguish competing explanations.

30 minutes

Open the activity

What you need

  • website fields
  • optional paper and pencil
  1. Read four quality observations involving alignment, friction, play, stiffness or stability.
  2. For each, list two possible causes without selecting one too early.
  3. Choose the evidence that would distinguish the causes.
  4. Write one stop–check–adjust–record plan with a single teacher-approved change.

Evidence: Cause/evidence matrix and one adjustment record, saved as formative practice.

Type the response, reasoning or record requested above. It autosaves in this browser.

Ready to save0 characters

Support: Use ‘observed’, ‘possible cause’, ‘evidence needed’ and ‘one approved change’ as separate columns.

Extension: Add a system-chain consequence for each possible cause.

Activity 9

Repeated-data detective

Use mean, range and pattern evidence instead of selecting one best result.

30 minutes

Open the activity

What you need

  • website fields
  • optional paper, pencil and ruler
  1. Check the headings and units of two supplied practice data tables.
  2. Calculate mean and range for each set.
  3. Identify one pattern and one possible anomaly.
  4. Choose keep, reverse or retest and justify it with CER.
  5. Name one limitation of the practice dataset.

Evidence: Calculations, anomaly note, CER decision and limitation, saved as formative practice.

Type the response, reasoning or record requested above. It autosaves in this browser.

Ready to save0 characters

Support: Mean describes centre; range describes spread; neither replaces attention to the full pattern.

Extension: Explain how an outlier could change the mean and what further evidence would help.

Activity 12

Authority, context and connected-systems inquiry

Use teacher-provided Aboriginal-led sources to recognise connected engineering relationships without appropriation or false equivalence.

35 minutes

Open the activity

What you need

  • website fields
  • optional paper and pencil
  1. Read the authoritative source extracts embedded by the teacher or integrator, then check each for named authority, specific place/system and publication context.
  2. Identify relationships among landscape, water, people, knowledge and maintenance that the source itself supports.
  3. Separate source-supported statements from unsupported generalisations.
  4. Write why the named cultural system must not be treated as a Catapult template or generic analogy.
  5. Record one respectful question that would require further teacher or community context.

Evidence: Source check, connected-system map and contextual statement, saved as formative practice.

Type the response, reasoning or record requested above. It autosaves in this browser.

Ready to save0 characters

Support: Name the source and the specific system; write only what that source supports; preserve distinct purpose and cultural authority.

Extension: Compare two authoritative accounts of the same named system and note how their purposes or audiences differ.
